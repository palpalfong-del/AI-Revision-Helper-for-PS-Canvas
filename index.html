各 AI 平台 API Key 取得入口一覽 / Where to Get API Keys
1. Google Gemini aistudio.google.com ↗

登入 Google AI Studio → 點選 Get API key / API keys → 選擇或建立 Google Cloud 專案產生金鑰（受地區政策限制）。

2. OpenAI (GPT 系列) platform.openai.com ↗

登入後前往 API keys 建立金鑰；正式呼叫需至 Billing 綁定付款方式與儲值。

3. Anthropic (Claude) platform.claude.com ↗

登入 Claude Console → Settings → API keys 建立金鑰（sk-ant- 開頭），並設定工作區額度。

4. OpenRouter（多模型聚合 · 推薦香港/跨境使用） openrouter.ai ↗

登入後前往 Keys 建立（sk-or- 開頭）；單一金鑰可切換 Gemini / GPT / Claude 等視覺模型，選「自訂 OpenAI 相容 API」填入即可。

5. 豆包（火山引擎·方舟） console.volcengine.com ↗

實名認證後進入火山方舟 (ARK) → API 密鑰管理建立金鑰，並於「在線推理」建立支援視覺的接入點取得 Endpoint ID。

6. xAI (Grok) / DeepSeek console.x.ai · platform.deepseek.com

登入各自開放平台進入 API Keys 建立（須選用支援 Vision 圖片輸入的模型版本）。
